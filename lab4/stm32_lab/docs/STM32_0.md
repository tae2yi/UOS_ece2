# STM32_0 · LED와 버튼
**10/12** · [목차](index.md)

이 문서는 **이번에 제공한 4주 실습 매뉴얼의 한 부분**이다. 같은 매뉴얼로 4주 전체를 진행한다.

먼저 [예제 시작과 전환](index.md#예제-시작과-전환)을 확인해 이전 실습 코드를 정리한다.

## 코드 읽기
- `GPIO_PinState`는 LOW/HIGH를 이름으로 나타내는 **enum 자료형**이다. `GPIO_PIN_RESET`은 LOW, `GPIO_PIN_SET`은 HIGH다.
- `uint32_t`는 음수 없는 32비트 정수다. 시간을 ms 단위로 저장한다.
- 함수 안의 `static` 변수는 다음 호출에서도 값을 기억한다. previous는 이전 버튼 상태, last_ms는 마지막 LED 변경 시간을 저장한다.
- `HAL_GPIO_ReadPin(포트, 핀)`은 현재 입력을 읽는다. `HAL_GPIO_WritePin(포트, 핀, 상태)`는 출력을 지정한 상태로 설정하고, `HAL_GPIO_TogglePin(포트, 핀)`은 현재 출력 상태를 반대로 바꾼다.
- 버튼 예제의 `&&`는 모든 조건이 맞아야 한다는 뜻이다. 현재 HIGH이면서 이전에는 LOW인 순간을 찾는다.

## 제공 예제 1 · 1초 간격 LED
메인 루프는 `polling_routine()`을 계속 호출한다. 현재 시간을 확인해 1000 ms가 지났을 때만 PA5 LED 상태를 바꾼다. 켜짐 1초, 꺼짐 1초이므로 전체 반복 주기는 2초다.

> [!TIP]
> **제공 코드 · ece2_474_routine.c의 polling_routine 교체**
>
> ```c
> void polling_routine(void)
> {
>     static uint32_t last_ms = 0;
>     static GPIO_PinState led_state = GPIO_PIN_RESET;
>     uint32_t now_ms = HAL_GetTick();
>
>     if (now_ms - last_ms >= 1000U)
>     {
>         last_ms = now_ms;
>         led_state = (led_state == GPIO_PIN_RESET)
>                     ? GPIO_PIN_SET : GPIO_PIN_RESET;
>         HAL_GPIO_WritePin(LED_ece2_GPIO_Port, LED_ece2_Pin, led_state);
>     }
> }
> ```

`조건 ? 참일 때의 값 : 거짓일 때의 값`이 삼항연산자다. 위 코드는 현재 상태가 RESET이면 SET을, 아니면 RESET을 선택해 led_state에 저장한다. 선택한 상태를 HAL_GPIO_WritePin에 전달한다.

이 보드의 PA5 LED는 SET(HIGH)으로 켜고 RESET(LOW)으로 끈다. led_state는 마지막으로 설정한 LED 상태를 기억한다. RESET은 여기서 핀을 LOW로 설정한다는 뜻이며, 보드를 재시작하는 RESET 버튼과 다르다.

SET을 여러 번 써도 계속 켜진 상태이고, RESET을 여러 번 써도 계속 꺼진 상태다. 반면 Toggle은 호출할 때마다 현재 상태를 반대로 바꾼다. 다음 버튼 예제에서는 Toggle을 사용한다.

## 제공 예제 2 · 버튼을 누르면 LED 변경
PC13의 사용자 버튼을 읽는다. 누르고 있는 동안 계속 바꾸지 않고, 누른 순간에 한 번만 바꾼다. 버튼 인터럽트 함수는 빈 상태로 둔다.

> [!TIP]
> **제공 코드 · 위 예제 대신 polling_routine 교체**
>
> ```c
> void polling_routine(void)
> {
>     static GPIO_PinState previous = GPIO_PIN_RESET;
>     static uint32_t last_press_ms = 0;
>     GPIO_PinState current = HAL_GPIO_ReadPin(BUTTON_ece2_GPIO_Port, BUTTON_ece2_Pin);
>     uint32_t now_ms = HAL_GetTick();
>
>     if (current == GPIO_PIN_SET && previous == GPIO_PIN_RESET
>         && now_ms - last_press_ms >= 200U)
>     {
>         last_press_ms = now_ms;
>         HAL_GPIO_TogglePin(LED_ece2_GPIO_Port, LED_ece2_Pin);
>     }
>     previous = current;
> }
> ```

200 ms 이내에 다시 검출되는 입력은 무시한다. 버튼 접점에서 생기는 짧은 반복 입력을 줄이기 위한 간단한 처리다.

## 직접 작성할 과제 · 총 2개

제공 예제 2개를 실행한 뒤, 아래 **STM32_0_과제1과 STM32_0_과제2를 모두 수행**한다. 두 과제의 정답 코드는 제공하지 않는다.

| 과제 | 해야 할 일 | 확인할 결과 |
|---|---|---|
| STM32_0_과제1 | 버튼으로 내장 LED의 상태 변경 간격 조절 | 1초 → 2초 → 4초 → 8초 → 1초 |
| STM32_0_과제2 | STM32_0_과제1을 외부 LED로 동작시키기 | 외부 LED에서도 같은 간격 변경 |

### STM32_0_과제1 · 버튼으로 LED 간격 변경

두 제공 예제를 합치고 **간격을 저장하는 변수 하나를 추가**한다. 내장 LED(PA5)를 사용한다.

- 버튼을 누를 때마다 LED 상태 변경 간격이 **1초 → 2초 → 4초 → 8초 → 1초** 순서로 바뀌어야 한다.
- 버튼을 누르지 않아도 LED는 선택한 간격으로 계속 깜빡여야 한다.
- 버튼을 계속 누르고 있어도 간격은 한 번만 바뀌어야 한다.

여기서 간격은 LED가 켜짐에서 꺼짐으로, 또는 꺼짐에서 켜짐으로 바뀔 때까지의 시간이다.

### STM32_0_과제2 · 외부 LED로 동작시키기

**STM32_0_과제1에서 작성한 코드**를 수정해, 내장 LED 대신 **PB0 또는 PB1에 연결한 외부 LED**로 같은 동작을 구현한다.

1. **PB0 또는 PB1 → 저항(330 Ω~1 kΩ) → LED 긴 다리(+)** 순서로 연결하고, LED 짧은 다리(-)는 보드의 **GND**에 연결한다.
2. `Core/Inc/main.h`에서 사용할 핀의 이름을 찾는다. PB0는 `GPIO_OUT1_ece2_Pin`·`GPIO_OUT1_ece2_GPIO_Port`, PB1은 `GPIO_OUT2_ece2_Pin`·`GPIO_OUT2_ece2_GPIO_Port`다.
3. 코드의 `LED_ece2_Pin`과 `LED_ece2_GPIO_Port`를 선택한 외부 LED의 핀과 포트 이름으로 바꾼다.
4. 버튼을 눌러 외부 LED의 상태 변경 간격도 **1초 → 2초 → 4초 → 8초 → 1초**로 바뀌는지 확인한다.

> [!IMPORTANT]
> **STM32_0_과제1과 STM32_0_과제2는 각각 동작을 확인한다.** STM32_0_과제1의 내장 LED 동작을 확인한 뒤 STM32_0_과제2로 진행한다. 외부 LED만 켜지는 것으로 끝내지 않고, 버튼으로 간격이 바뀌는 것까지 확인한다.
