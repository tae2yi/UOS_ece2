# STM32 실습 매뉴얼

[README로 돌아가기](../README.md) · [4주 실습 계획 PDF](STM32_4week_plan.pdf)

**4주 실습에 필요한 매뉴얼은 모두 이 리포지토리에 정리되어 있다.** 매주 별도의 추가 매뉴얼은 제공하지 않으므로, 아래 목차에서 해당 주차의 문서를 확인하며 진행하면 된다. STM32_0~3은 하나의 매뉴얼을 주차별로 나눈 구성이다. 하나의 프로젝트를 사용하며, 제공 코드는 각 주차의 콜아웃에 있다.

| 날짜 | 매뉴얼 | MCU 과제 | 내용 |
|---|---|---|---|
| 10/12 | [STM32_0](STM32_0.md) | 과제1~2 · 2개 | 폴링 루프, LED, 버튼, 간격 변경 과제 |
| 10/19 | [STM32_1](STM32_1.md) | 과제3~4 · 2개 | 버튼·타이머 인터럽트, PWM |
| 10/26 | [STM32_2](STM32_2.md) | 과제5~7 · 3개 | PC 입출력, STM32–FPGA UART |
| 11/2 | [STM32_3](STM32_3.md) | 과제8~12 · 5개 | SPI · MCU–MCU·MCU–FPGA·FPGA–FPGA 송수신 |

> [!NOTE]
> **10/26 STM32_2에서 10분 퀴즈를 실시할 수 있음.** 실시 여부와 범위는 별도로 안내한다.

## 조별 장비 연결

- **MCU–FPGA:** 자기 조의 MCU와 FPGA를 사용한다. 옆 조와 함께할 필요가 없다. STM32_2와 STM32_3_과제10·11에 해당한다.
- **MCU–MCU / FPGA–FPGA:** 장비 두 대가 필요하므로 **A–B, C–D, E–F, G–H, I–J**끼리 연결하고 역할을 교대한다. STM32_3_과제9·12에 해당한다.

## MCU와 FPGA의 핀 설정

- **MCU:** IOC 설정에서 생성된 C 코드로 핀 기능을 정한다. 제공 템플릿의 핀 이름과 주차별 연결표를 사용한다. MCU에는 XDC가 없다.
- **FPGA:** FPGA 프로젝트의 XDC로 신호와 FPGA 칩의 핀을 연결한다. 매뉴얼의 XDC 수정 안내는 FPGA 쪽 작업이다.

## 예제 시작과 전환

주차가 바뀌거나 다른 제공 예제를 실행할 때는 다음 순서로 준비한다. 과제에서 이전 코드를 이어 쓰라고 지정한 경우에는 해당 코드를 보존한다.

1. 진행 중인 디버깅을 종료한다.
2. `ece2_474_routine.c`의 이전 실습 코드를 따로 보관한다.
3. 새 예제를 시작할 때는 `ece2_474_init()`의 타이머·PWM·UART 시작 호출을 모두 주석 처리하고, 이전 실습에서 추가한 초기화 코드도 제거한다. `polling_routine()`과 실습용 ISR 함수의 이전 동작 코드를 비운다. 필요한 시작 호출과 동작만 이번 예제에 맞게 넣는다.
4. 함수 선언과 아래쪽 `HAL_…Callback` 연결 코드는 유지한다. 콜아웃이 함수 전체를 제공하면 기존 함수를 **교체**한다. 같은 이름의 함수를 추가로 만들지 않는다.
5. 저장하고 Build한 뒤 **F5로 새 프로그램을 보드에 다운로드**한다. main에서 멈추면 F5를 한 번 더 누른다. Build만 하거나 RESET만 누르면 새 프로그램으로 바뀌지 않는다.

`Ctrl + /`로 선택한 줄의 주석을 설정·해제할 수 있다. LED 예제에 이전 타이머·버튼 처리까지 남아 있으면 서로 다른 코드가 같은 LED를 바꾸게 된다.

| 예제 | ece2_474_init() | 동작을 작성할 함수 |
|---|---|---|
| STM32_0 LED·버튼 폴링 | 빈 상태 | polling_routine |
| STM32_1 버튼 예제 | 빈 상태 | button_isr_p7 |
| STM32_1 TIM6 예제 | TIM6 시작 | tim6_isr_p4 |
| STM32_1 PWM 과제 | PWM 시작 | button_isr_p7 |
| STM32_2 UART 예제 | 빈 상태 · UART 인터럽트 수신 시작 안 함 | polling_routine |
| STM32_3 SPI 마스터 | 빈 상태 · 기본 SPI 설정 사용 | polling_routine |
| STM32_3 SPI 슬레이브 | 매뉴얼의 슬레이브 초기화 | polling_routine |

STM32_1_과제3은 버튼과 TIM6 ISR을 함께 사용하며, 과제4는 버튼 처리 내용을 PWM 제어로 바꿔 별도로 확인한다.

## FPGA 개별 실습

[8개 실습의 모듈별 Verilog와 테스트벤치](FPGA_additional.md)


기존 3주 실습과 기능이 겹치는 예제를 제외하고, 아직 수행하지 않은 **8개를 STM32_0~2에 나누어** 진행한다. STM32_3은 SPI 과제에 집중한다. 아래 순서는 지정된 수행 순서다.

| 날짜 | 주차 | FPGA 실습 순서 | 개수 |
|---|---|---|---:|
| 10/12 | STM32_0 | ① 4비트 곱셈기 · ② BCD를 이진수로 변환 | 2 |
| 10/19 | STM32_1 | 피아노 → 신호등 제어 → ADC | 3 |
| 10/26 | STM32_2 | 서보모터 제어 → SRAM 읽기·쓰기 → DAC | 3 |
| 11/2 | STM32_3 | SPI 과제8~12 · 교재 추가 실습 없음 | 0 |

**각자 장비와 함께 제공된 교재를 보고 시뮬레이션과 실제 보드 시연을 수행한다.** 시뮬레이션에서는 입력과 출력 파형을 확인하고, 실제 보드에서는 교재의 장치 연결과 핀 설명에 따라 동작을 확인한다. 두 결과를 비교한다.

예제 ZIP 이름과 확인할 내용은 각 주차 매뉴얼에 적혀 있다. 피아노와 신호등은 기존에 배운 원리를 활용하는 새로운 응용 실습이다. 서보는 `servo_ctrl.zip`을 사용하며 빈 `servo.zip`은 사용하지 않는다.
