\begin{frame}{FPGA에서 STM32로}
\fontsize{10}{13}\selectfont
\textbf{회로를 구성하는 실습에서, 준비된 회로를 제어하는 실습으로.}
\vspace{0.3cm}
\begin{columns}[T]
\begin{column}{0.47\textwidth}
\begin{block}{지난 3주 · FPGA}
\fontsize{10}{13}\selectfont
Verilog로 회로를 구성\\[0.18cm]
여러 회로가 동시에 동작\\[0.18cm]
카운터·FSM·UART 직접 설계
\end{block}
\end{column}
\begin{column}{0.47\textwidth}
\begin{block}{앞으로 4주 · STM32}
\fontsize{10}{13}\selectfont
C 프로그램으로 장치를 제어\\[0.18cm]
CPU가 기계어 명령을 실행\\[0.18cm]
GPIO·타이머·UART·SPI 사용
\end{block}
\end{column}
\end{columns}
\vspace{0.4cm}
\textbf{FPGA: 회로 구성 \qquad STM32: 프로그램으로 제어}
\par\vspace{0.18cm}\fontsize{9}{12}\selectfont
MCU는 CPU·메모리·주변장치를 하나에 모은 마이크로컨트롤러다.\\
주변장치는 CPU와 별도로 신호를 만들거나 데이터를 송수신한다.
\end{frame}
