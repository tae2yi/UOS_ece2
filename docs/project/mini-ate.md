## 사용자 방향
- 진로: **로보틱스 + 반도체 공정**. 진로 슬라이드에는 둘 다 쓰고, 프로젝트는 하나를 확실히.
- **클러스터 툴(웨이퍼 이송 암) 모형은 보류** — 사용자가 "그냥 모터로 판 옮기는 것, 반도체와의 연결이 겉포장"이라고 지적. 주제의 기술적 연결이 진짜인지 솔직하게 평가할 것.

## 미니 ATE 안
- FPGA: 74HC 논리 IC 기능 테스트(패턴 인가·비교, 고착 고장 주입 스위치). DUT는 보드 브레드보드 BDIO 16핀에 꽂음(100 Ω 직렬·버스 스위치 내장, DIP SW5).
- STM32: DAC/ADC로 2N7000 Vth·1N4148 I-V·LED Vf 측정(op-amp 버퍼, R 470 Ω~1 kΩ, 3.3 V 한계). 같은 소자 여러 개로 **공정 산포** 분포 → 반도체 공정과 연결.
- 흐름: 단락 검사(BIN4) → 기능 테스트(BIN2) → 파라메트릭(BIN3) → 판정·리포트(LCD/FND/LED, PC Python). STM32–FPGA는 SPI 레지스터 맵.
- 시료: 74HC00 정상, 74HC08/32/86(같은 핀 배치 → 안전한 오삽입), 74HC02(핀 배치 다름, 1 kΩ 직렬 추가 시에만), 74HC74/161(순차, 확장), 2N7000 20개, 1N4148, R/Y/G LED, 1 kΩ 1% 교정용. **HC 계열만**(LS는 5 V). DUT 전원은 실험실 전원공급기 3.3 V·전류 제한 ~50 mA. 디바이스마트·엘레파츠, 1~2만 원.
- 테스터 자체 검증: 정밀 저항으로 교정, 멀티미터 비교, 보드 내장 ADC와 교차, 진리표·고장 모델 시뮬레이션·실물 일치, 오실로스코프 타이밍, 10회 반복.
- 확장: 칩 자동 판별, 순차 회로 테스트, 보드 내장 서보로 BIN 분류기(로봇 요소).
- 일정 초안: ~11/16 부품·제안서·레지스터 맵 / 11/23 패턴 엔진·고장 모델 TB | DAC 버퍼·ADC / 11/30 SPI 슬레이브·74HC00 실물 | 2N7000 스윕·Vth / 12/7 LCD·FND | 시퀀서·PC 리포트 / 12/14 확장 | 반복 측정·산포 / 12/21 시연.
