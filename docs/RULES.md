## 대화 방식

- 사용자는 짧게 지시한다("이어서 진행", "그렇게 진행하자", "커밋하고 푸시해줘"). 직전 보고에서 제안한 다음 단계를 그대로 진행하라는 뜻.
- 실습 당일(월요일 오후)에는 보드 앞에서 실시간 질문이 온다("이건 뭘 확인하면 되지?", "DIP_SW1은 어디에 있어?"). 핀·스위치·LED가 무엇을 해야 정상인지 **짧고 구체적으로** 답하고, 필요하면 수정 bitstream을 바로 만들어 push 한다.
- 결과를 보고할 때 확인 못 한 것(교재 대조 안 한 ISBN, 추정 핀, 보드 미검증)은 분명히 밝힌다.
- 프로젝트 주제는 **진짜 기술적 연결**을 중시한다. 억지 포장(예: 클러스터 툴 = 그냥 모터로 판 옮기기)은 싫어한다.
