# STM32_1 · 인터럽트와 PWM
**10/19** · [목차](index.md)

이 문서는 **이번에 제공한 4주 실습 매뉴얼의 한 부분**이다. 같은 매뉴얼로 4주 전체를 진행한다.

먼저 [예제 시작과 전환](index.md#예제-시작과-전환)을 확인해 이전 실습 코드를 정리한다.

## 코드 읽기
- `TIM_HandleTypeDef`는 타이머의 설정과 상태를 묶은 **구조체 자료형**이다. htim6와 htim3는 main.c에 정의된 변수다.
- `&htim6`는 htim6의 주소다. 시작 함수에 이 주소를 전달해 TIM6를 지정한다.
- `extern`은 다른 파일에 정의된 변수를 사용하겠다는 선언이다.
- `++count`는 횟수를 1 늘린다. 10번이 되면 LED를 바꾸고 count를 0으로 돌린다.
- `__HAL_TIM_SET_COMPARE`는 PWM에서 켜진 시간에 해당하는 값을 설정하는 매크로다. 이번 설정은 한 주기가 1000칸이므로 500은 절반이다.
- 함수 앞의 `static`은 현재 C 파일 안에서만 사용하는 함수라는 뜻이다. 함수 안 변수의 static과 구분한다.

[자료형·enum·구조체 등 C 문법 설명](C_basics.md)

htim6·htim3의 extern 선언은 제공된 ece2_474.h에 이미 있다. 추가 선언 없이 바로 사용한다. ece2_474_init()에 주석으로 준비된 시작 호출 중 필요한 줄을 주석 해제한다.

## 버튼 인터럽트
메인 루프에서 버튼을 읽는 대신, 버튼 입력이 발생하면 호출되는 `button_isr_p7()`을 사용한다. STM32_0의 버튼 폴링 코드는 지운다. 아래 함수는 기존 함수의 내용을 교체한다.

> [!TIP]
> **제공 코드 · ece2_474_routine.c**
>
> ```c
> static void button_isr_p7(void)
> {
>     static uint32_t last_ms = 0;
>     uint32_t now_ms = HAL_GetTick();
>     if (now_ms - last_ms >= 200U)
>     {
>         last_ms = now_ms;
>         HAL_GPIO_TogglePin(LED_ece2_GPIO_Port, LED_ece2_Pin);
>     }
> }
> ```

## 주기 타이머
TIM6는 시작한 뒤 100 ms마다 `tim6_isr_p4()`를 호출한다. 10번을 세면 1초다. 이 예제는 버튼 예제와 별도로 실행하고, LED를 바꾸는 다른 코드는 빈 상태로 둔다.

> [!TIP]
> **제공 코드 · ece2_474_routine.c의 ece2_474_init 함수 안에 추가**
>
> ```c
> HAL_TIM_Base_Start_IT(&htim6);
> ```
>
> **ece2_474_routine.c의 기존 함수 교체**
>
> ```c
> static void tim6_isr_p4(void)
> {
>     static uint32_t count = 0;
>     if (++count >= 10U)
>     {
>         count = 0;
>         HAL_GPIO_TogglePin(LED_ece2_GPIO_Port, LED_ece2_Pin);
>     }
> }
> ```

## PWM 출력
PB4는 1 kHz PWM 출력이다. 내장 LED PA5와 다른 핀이다. PB4와 GND를 계측기에 연결해 켜진 시간의 비율을 확인한다.

> [!TIP]
> **제공 코드 · ece2_474_routine.c의 ece2_474_init 함수 안에 추가**
>
> ```c
> HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
> __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 500U);
> ```

현재 설정에서 250, 500, 750은 각각 25%, 50%, 75%에 해당한다.

## 직접 작성할 과제 · 총 2개

아래 STM32_1_과제3과 STM32_1_과제4를 각각 수행한다. 정답 코드는 제공하지 않는다.

### STM32_1_과제3 · STM32_0_과제1을 ISR 기반으로 재현

[STM32_0_과제1](STM32_0.md#stm32_0_과제1--버튼으로-led-간격-변경)에서 구현한 동작을 **버튼 인터럽트와 TIM6 타이머 인터럽트**로 다시 구현한다.

- `button_isr_p7()`에서 버튼을 누를 때마다 LED 상태 변경 간격을 **1초 → 2초 → 4초 → 8초 → 1초**로 변경한다. 버튼을 한 번 누르면 간격도 한 번만 바뀌어야 한다.
- `tim6_isr_p4()`는 100 ms마다 호출된다. 호출 횟수를 세어 선택한 간격마다 LED 상태를 바꾼다.
- `ece2_474_init()`에서 TIM6 인터럽트를 시작한다.
- `polling_routine()`에서 버튼을 읽거나 시간을 확인해 LED를 바꾸던 코드는 제거한다. 버튼과 LED의 동작은 ISR에서 처리한다.
- STM32_0_과제1과 같은 **내장 LED(PA5)**로 동작을 확인한다.

두 ISR에서 함께 사용하는 간격 변수는 함수 밖에 선언한다. ISR에서 바뀌는 값을 다른 실행 흐름에서도 읽는 경우 `volatile`을 붙여 컴파일러가 매번 저장된 값을 읽도록 한다. 단, volatile은 여러 연산을 한 번에 실행하도록 보장하는 기능은 아니다.

### STM32_1_과제4 · 버튼으로 PWM 비율 변경·C 디버거 사용

버튼을 누를 때마다 PWM 비율을 **25% → 50% → 75% → 25%**로 변경한다. 헤더에 선언된 htim3를 사용하고, PWM 시작은 `ece2_474_init()`에 작성한다. STM32_1_과제3의 버튼 처리를 대신하여 STM32_1_과제4를 별도로 확인한다.
**C 디버거 사용법도 익힌다.** 아래 순서로 코드 실행과 변수 변화를 직접 확인한다.

1. `button_isr_p7()`의 PWM 변경 코드에 중단점을 설정한다. 코드 줄 왼쪽을 클릭하거나 **F9**를 누른다.
2. **F5**로 디버깅을 시작하고, main에서 멈추면 F5를 한 번 더 누른다. 보드 버튼을 눌러 설정한 중단점에서 멈추는지 확인한다.
3. **변수(Variables)** 또는 **조사식(Watch)**에서 현재 PWM 비율을 저장한 변수를 확인한다.
4. **F10**으로 한 줄씩 실행하며 변수와 PWM 설정값이 어떻게 바뀌는지 확인한다. 함수 내부를 살펴볼 때는 **F11**, 다시 계속 실행할 때는 **F5**를 사용한다.
5. 중단점을 해제하고 정상 실행 상태에서 버튼으로 비율이 순환하는지 확인한다. 디버깅 종료는 **Shift + F5**다.

중단점으로 멈춘 시간은 정상 동작의 시간 측정값으로 사용하지 않는다. PWM 파형은 중단점을 해제하고 실행한 상태에서 확인한다.

> [!NOTE]
> 인터럽트 함수 안에서는 printf, 입력 대기, HAL_Delay를 사용하지 않는다. 우선순위는 TIM6가 4, 버튼이 7이다.

**장비와 함께 제공된 교재**에서 해당 실습을 찾아, 아래 순서대로 **각자 시뮬레이션과 실제 보드 시연**을 해본다.

| 순서 | 실습 | 예제 ZIP | 확인할 내용 |
|---|---|---|---|
| 1 | 피아노 | `piano.zip` | 버튼에 따라 다른 음계가 나오는지 확인한다. |

시뮬레이션에서는 입력과 출력 파형을 확인한다. 실제 시연은 교재의 장치 연결과 핀 설명을 확인한 뒤 진행하고, 파형에서 예상한 결과와 비교한다. 이번 주차의 3개를 순서대로 수행한다.

추가된 변환 장치 실습은 FPGA로 외부 장치를 제어하는 실습이다. STM32 내부 ADC·DAC는 사용하지 않는다.
